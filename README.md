# Jeffreys Divergence Flags Unreliable Flow Cytometry Predictions

Code accompanying *"Jeffreys Divergence Flags Unreliable Flow Cytometry Predictions"* (J. Legrand et al.).

## Setup & Data

Create the environment with `conda env create -f env.yml && conda activate jeffreys-flow-cytometry`.

Clinical flow cytometry datasets (GEIL and ELN cohorts) are not publicly available. Local paths to preprocessed event files and metadata are configured in `config.yml`.

## Files
### Scripts to compute distances
- `compute_pairwise_distances.py`: Fits subject-level GMMs ($K=8$), computes pairwise Jeffreys divergences across cohorts, and exports pairwise distances and 2D non-metric MDS embeddings to `output/`.

- `run_distance_to_fisher.py`: Trains the Fisher kernel SVM classifier over 20 runs, computes Monte Carlo Jeffreys divergences between test subject GMMs and the training reference GMM, calibrates the rejection threshold on a 20% validation split, and saves evaluation metrics and retention curves to `output/distance_to_fisher_results.json`.

### Results scripts

- `plot_distance_to_fisher.py`: Prints evaluation statistics and generates the retention curves (`figures/rejection_curves.png`; Fig. 3) and GMM parameter comparison (`figures/methods-evaluation.eps`; Fig. 4).
- `permanova_analysis.py`: Runs a 1,000-permutation PERMANOVA on the exported pairwise distance table to test for cohort batch effects.
- `plot_npm_distances.py`: Plots the 2D MDS embedding coloured by cohort (`figures/mds.eps`, `figures/mds.png`; Fig. 2).

Since some of those scripts analyse the results generated by the computing scripts,
the head path variables of `plot_distance_to_fisher.py` and `permanova_analysis.py`
must be modified accordingly.

### Modules and config
- `run_config/simple_config.py`: Task, pipeline (`fisher_svm`), and seed configuration.
- `source/`:
  - `scaling.py`: `CytoScaler` for marker-wise Z-score normalization on 3D `(subjects, cells, markers)` arrays.
  - `models/fisher_kernel.py`: `FisherKernelGenerator` and `FisherEmbedding` transformer.
  - `dataset/`: Dataset loaders (`eln.py`, `geil.py`, `cross_domain.py`) for the Source, Time-shifted, and Panel-shifted cohorts.
  - `distance_analysis.py` & `utils.py`: Evaluation and config helpers.
- `test/`: Unit tests for `FisherKernelGenerator` (`test_fisher_embedding.py`), `CytoScaler` (`test_scaling.py`), and curve misclassification rate calculation (`test_distance_to_fisher.py`). Run with `pytest`.
