# Test Fisher vectors
The test functions by themselves might seem a bit cryptic, so here
are the ideas behind the `test_mu_gradient` function. The idea behind `test_sigma_gradient` is the same, although it is a bit more work to find the expected value of the corresponding Fisher vector.

## Test $\mathcal{G}_{\mu}$
Suppose we have two gaussian mixture models of parameters 
$(\mu_a, \sigma_a, w_a)$ and $(\mu_b, \sigma_b, w_b)$.

We want to test the Fisher embeddings computed from these two GMM for a given random variable 
$X = \{X_1, X_2, ..., X_T\}$.

First we generate $X$ from $\mathcal{N}(\mu_a - \delta, \sigma_a)$,
with $\delta$ a small float.

Next, we compute the Fisher embedding using the pipeline we want to
test.

```python
delta = 0.1
X = rng.normal(loc=loc_a - delta, scale=scale_a, size=(1, 5000, n_features))
embeddings = gen.G(X)
```

Recall that the embedding is just a concatenation of Fisher vectors
computed for each parameter $\mu$ and $\sigma$ ($w$ is discarded in general), as defined in :
Perronnin, F., Sánchez, J., & Mensink, T. (2010). Improving the Fisher Kernel for Large-Scale Image Classification. In K. Daniilidis, P. Maragos, & N. Paragios (Eds.), Computer Vision – ECCV 2010 (pp. 143–156). Springer. https://doi.org/10.1007/978-3-642-15561-1_11



### Testing embedding from GMM a
Let's extract the values corresponding to $\mathcal{G}_{\mu, a}$ : 
```python
G_mu_a = embeddings[:n_features]
```
The idea is that we can easily know from the formulas the expected value of that quantity, since we chose the distribution of $X$ (we consider that $\gamma_a(1) = ... = \gamma_a(T) = 1$) :

$$\mathbb{E}[\mathcal{G}_{\mu , a}] = -\frac{\delta}{\sigma_a\sqrt{w_a}}$$

Knowing that information, we perform a t-test of `G_mu_a` against its theorical value and assert that the null hypothesis is not rejected.

```python
result = ttest_1samp(G_mu_a, expected_value, alternative="two-sided")
assert result.pvalue > 0.1, "Gradient scores are not consistent with the given sample and GMM parameters"
```

Intuitively, the vector $\mathcal{G}_{\mu, a}$ represents the shift
$\mu_a$ should follow to better represent $X$, so we expect something that's negative and proportional to $\delta$.

### Testing embedding from GMM b
If we assume that $\mu_a$ and $\mu_b$ aren't too close and that the variances were choosen to be small enough, we expect $X$ to be almost not generated by GMM b at all. 
In that case, $\gamma_t(b)$ should be close to zero for all $t \in \{1, ..., T\}$, and as result the corresponding Fisher vector should only contain $0$ entries. All we have to do is assert that :
```python
G_mu_b = embeddings[2*n_features:3 * n_features]
assert np.all(np.isclose(G_mu_b, 0)), "Gradient scores are not consistent with the given sample and GMM parameters"

```
